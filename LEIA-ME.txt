LicitaGestao - correcao da aba Prazos da participacao

O que muda:
- A aba Prazos em /participacoes/:id deixa de ser placeholder.
- Ela busca os prazos reais da licitacao vinculada.
- Exibe sessao e validade da proposta, com data, dias restantes/vencidos e plataforma.
- Usa os mesmos dados que alimentam os alertas e notificacoes do LicitaGestao.
- Mantem os botoes SEOBRA e Plataforma na tela da participacao.
- Nao cria migration, nao altera dados e nao executa seed.

Como aplicar:
1. Copie backend/ e frontend/ para a raiz do projeto atual, substituindo os arquivos.
2. Rode:
   npm run typecheck
   npm run lint
   npm run build
3. Se passar:
   git add .
   git commit -m "Exibe prazos na licitacao da empresa"
   git push
4. No Render, use Deploy latest commit se necessario.

Observacao:
Nao e necessario executar db:generate, migrate ou seed para este ajuste.
